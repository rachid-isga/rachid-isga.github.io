Test 16 Personalities

Interactive multilingual personality assessment platform with Livewire 4.2 reactive questionnaire, complete 16 MBTI archetypes, PayPal SDK checkout, and personalized DomPDF analysis reports.

Primary Stack PHP 8.2, Laravel 12, Livewire 4.2, Spatie Translatable, Barryvdh DomPDF, Srmklive PayPal
UI Reactivity Single-Page Zero-Reload Assessment (Livewire 4.2 + Tailwind)
Monetization Engine PayPal v2 API Checkout & PDF Report Fulfillment

Project Overview

Test 16 Personalities is an interactive psychometric assessment web application inspired by personality classification systems. Built with Laravel 12, Livewire 4.2, and Tailwind CSS, it features a fluid multi-step test, 4-dimensional scoring algorithm (E/I, S/N, T/F, J/P), comprehensive archetype profiles, multilingual translation support, and an automated PDF report generation and sale pipeline using PayPal SDK.

Problem & Solution

The Challenge

Traditional online quizzes suffer from disruptive page reloads between questions, lack multi-dimensional trait balancing, and have disjointed checkout and report delivery flows.

The Engineered Solution

Leveraging Livewire 4.2, the questionnaire progresses instantaneously without reloads. Upon completion, users receive instant archetype breakdowns and can purchase full psychological analysis dossiers generated dynamically via DomPDF and fulfilled through PayPal webhooks.
