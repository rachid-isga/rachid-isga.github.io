Pharma Core Application

Next-generation pharmaceutical ERP refactor featuring clean architecture domain services, customer digital wallet ledgers, dynamic tiered pricing, and Spatie permission auditing.

Primary Stack PHP 8.2, Laravel 12, Spatie Permissions 6.25, Owen-It Auditing 14.0, Alpine.js, Tailwind CSS

Database Entities 64 Migrations (Products, Sales, Stock Movements, Audits, Wallets)

Project Overview

Pharma Core Application represents a modernized architectural refactoring of enterprise healthcare management. Built on Laravel 12, Spatie Permissions v6, and Owen-It Auditing v14, it introduces customer store credit digital wallets, tiered pricing rules for wholesale and retail tiers, and immutable audit logs for regulatory compliance.

Problem & Solution

The Challenge

Managing complex retail and wholesale pharmacy operations with customer store credit, tiered discounts, and multiple staff roles without a strict audit trail leads to accounting discrepancies and security liabilities.

The Engineered Solution

Pharma Core implements clean domain services, double-entry wallet ledgers (`ClientWalletTransaction`), multi-tier price rules (`DiscountRule`), and full transaction auditability powered by Owen-It Auditing.
